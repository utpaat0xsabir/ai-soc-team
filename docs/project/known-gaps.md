# Known gaps and release risks

| Gap | Risk | Closure evidence |
|---|---|---|
| B4 Gate 1 live enforcement | Target drift, unauthorized sessions, unsafe cleanup or premature freeze release. | Independently bind the exact disposable target and approval. Verify admission/freeze, authenticated event coverage and independent teardown on an authorized fixture. Reconcile evidence custody. |
| B4 Gate 2 historical digest and rehearsal | Unexplained DDL identity difference and unverified rehearsal outcome. | Resolve or independently disposition `0eafe3f3`. Obtain separate approval and verify guarded execution, postconditions and recovery. |
| Restricted PostgreSQL and Wazuh rollout | Application tenant guards can be bypassed by overprivileged infrastructure roles. Shared source identity can misroute evidence. | Test actual restricted logins and grants, independently establish source-to-tenant scope, and test partial results and recovery. |
| Model rollout | The candidate local adapter does not establish live production orchestration or model quality. | Independently authorize a narrow local synthetic capability. Verify receipts, isolation, bounded inference, abstention and deterministic fallback. |
| Trust and gateway composition | Offline authorization and disclosure paths do not establish end-to-end operational enforcement. | Independent review, exact version and endpoint binding, authorization tests and authenticated audit/evidence receipts. |
| Cases, L2/L3, retrieval and response | Operational workflow and independent verification services are incomplete. | Ship versioned case and handoff contracts and synthetic end-to-end tests. Activate retrieval and action adapters only after tenancy and policy review. |
| Audit custody and operations | Hash chains alone cannot establish protection against privileged history replacement or storage rollback. | External checkpoint retention, independently tested restore, bounded retention and custodian procedures. |
| Contributor and deployment hygiene | Offline selectors coexist with database fixtures. Testing and runtime provenance vary by environment. | Document reproducible guarded test invocation, separately pin live fixtures, document review-time exclusions, and preserve undelivered candidate status. |
