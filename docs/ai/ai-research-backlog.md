# AI research backlog

All items are proposed. Favor projects with a frozen synthetic dataset, a deterministic comparator and a failure case. Priorities describe engineering order rather than dates.

| Priority and size | Problem and approach | Required data and dependencies | Benefit and security risks | Evaluation and first milestone |
|---|---|---|---|---|
| P1 starter, small | **Structured L1.** Validate local model JSON and distinguish unsupported findings from abstention. | Synthetic alerts, evidence IDs, current task/result contracts and one local model fixture. | Reviewable outputs and lower parsing failures. Risks are invented details and leaked context. | Label 20 cases with benign and uncertain controls, compare to fake-provider outcomes, and reject all malformed or unknown citations. |
| P1 starter, small | **Security retrieval.** Compare exact ID lexical search with local embedding search over one curated snapshot. | Reviewed ATT&CK data, one local embedding model and per-tenant test fixture corpus. | Faster retrieval of valid context. Risks are poisoned text and access drift. | Complete the [offline RAG milestone](rag-architecture.md), publish metrics, and require zero unauthorized results. |
| P1 starter, small | **Local model optimization.** Quantize a tier-specific candidate to reduce cost. Compare structured output with the unquantized baseline. | Model rights, same labeled cases, local engine and hardware record. | Smaller runtime and predictable budgets. Risks are quality loss and supply-chain drift. | Measure memory, latency, structured validity and unsupported claims on the same 30 cases. Review LoRA, fine-tuning and distillation only with suitable data rights and benefit. |
| P2 intermediate | **Correlation and timelines.** Group event sequences and entity observations using deterministic windows and compare clustering or baselines. | Normalized fixture events, labeled process/entity links and benign controls. | Better scope and ordering. Risks include clock skew, false merges and tenant leakage. | Produce one reproducible timeline, score event order and false merges, and deny all cross-tenant edges. |
| P2 intermediate | **Detection engineering.** Generate candidate Sigma-style rules, explain matches and compare ATT&CK coverage. | Reviewed rule schemas, positive and benign negative fixtures. | Faster rule authoring and fewer false positives. Risks are unsafe deployments and brittle rules. | Produce one candidate with reviewed rule tests and a coverage report. Test positive/negative behavior and keep rollout separate. |
| P2 intermediate | **Intelligence evaluation.** Fuse known conflicts across sources with expiry and explicit abstention. | Synthetic feed snapshots and disclosure rules. | Clear provenance under contradiction. Risks are stale indicators and sensitive disclosures. | Test conflicting/expired indicators and show zero denied outbound lookups or cross-tenant cache hits. |
| P3 advanced | **Knowledge graph and Graph RAG.** Build a tenant-qualified evidence projection and compare traversal-assisted retrieval. | Evidence lineage, entity fixtures, document retrieval baseline and graph access model. | Explainable investigations and campaign linkage. Risks are ambiguous joins and unsupported paths. | Trace one incident with cited edges and compare path recall and unsupported links against hybrid retrieval. Deny every cross-tenant hop. |
| P3 advanced | **Controlled agentic investigation and hunting.** Compare hypotheses using approved evidence requests, bounded hunt-query proposals and structured handoffs. | Versioned case fixtures, gateway policy and reproducible L1/L2/L3 handoff harness. | Better scope and advanced triage. Risks are tool overreach, policy skips and confirmation bias. | Run one synthetic investigation with competing explanations, denial paths and human escalation. Require accurate citations and zero unauthorized transitions. |
| P3 advanced | **Governed incident memory.** Reuse validated prior incidents, analyst corrections and response outcomes. | Rights-reviewed, versioned decisions and retention rules; tenant-safe retrieval and revocation. | Better lessons across authorized cases. Risks are poisoned feedback, stale truth and disclosure. | Rebuild one memory snapshot from adjudicated fixtures and demonstrate correction and revocation remove stale recall. |
| P3 advanced | **Cross-source evidence fusion.** Correlate bounded aliases and provenance across alert, identity and asset sources. | Two fixture connectors, stable temporal IDs and case model. | Better campaign-level scope and evidence diversity. Risks are false joins and conflicting source origin. | Compare supported cross-source associations against labeled cases and abstain on ambiguous identity. |

Use model output as a proposal throughout. Local experiments do not grant runtime privileges. [Model evaluation](model-evaluation.md)
